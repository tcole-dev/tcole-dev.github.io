给你一个非负整数数组 nums ，你最初位于数组的 第一个下标 。数组中的每个元素代表你在该位置可以跳跃的最大长度。

判断你是否能够到达最后一个下标，如果可以，返回 true ；否则，返回 false 。

  • 0 <= nums[i] <= 105

思路

我们可以将数组中每个元素都视为能量，我们从nums[0]开始跳跃，每次移动一格都需要消耗一点能量。

我们每当移动后，判断该格的能量和自己拥有的能量哪个更大，碰到更大的能量，说明本轮跳（连续移动）到该索引后，可以走得更远。我们吞掉该格的能量，表示跳跃一次。

如何判断能否到达n - 1？

  • 每次移动后，power--，如果此时power < 0，说明本来能量为0，本就无法到达本格，吃不了本格的能量，直接饿死了，return false
  • 若遍历完毕（即到达n - 1），仍然没有饿死，则return true

思路

本题中，要求的是跳跃次数最少的方式，所以之前的方式就不太合适了，比如

在上一题中，我们的目标是到达n - 1，所以每次跳动，都需要保证的是可以获取更大的能量，跳得远不远无所谓，所以在这个例子中会跳动5次。

在本题中，我们每次跳动不一定需要获取更大的能量，而是保证每次跳跃更远，但如果直接耗尽当前能量跳到最远处，可能还会有这种情况：

  • 如果跳动方式： 2 -> 1 -> 1 -> 4，次数为3
  • 若：2 -> 3 -> 4，次数只有2。所以我们每次跳动都需要保证本次能量和目标索引的能量之和最大
