Golang 语法基础

数据类型

Go的变量主要包含：

  • 整数型：uint（无符号整型，分8、16、32位等多种，如uint8等价于 byte）、int（同理具有多种不同位的类型）

  • 浮点数：float（分float32、float64）

  • 复数

  • 字符类型：byte（常用于ASCII码值）、rune（等价于int32，表示Unicode字符）、string（可转为[]byte）

  • 派生类型：数组（[length]int，使用较少）、切片（[]int, 使用较多）、map（[key]value）、指针、函数、结构体、接口（interface{}）、通道（chan）

变量

变量的定义：

Go使用var声明变量，写法为 var name type

更常用的方法是使用 :=，同时声明和赋值，同时 := 可以自动判断变量类型，不需要显式写变量的数据类型。但 := 只能用在函数内部定义局部变量，不能用于全局变量的声明

slice 切片、map、chan类型的变量创建比较特殊，需要使用make()函数

map、chan变量本质上是一个指针，指向hmap、hchan结构体，slice则是一个结构体，内部维护一个指向数组的指针

其中map、chan若使用 var m map[string]int、var ch chan int时，变量仅为一个空指针，没有hmap、hchan对象，进行任何操作都会报错

而slice在声明后，底层指针为nil,没有数组，此时存入、访问其中的元素都会报错，但append不受影响，会自动创建底层数组。

其他类型如string、int在var时，会分配内存。make()方法在创建slice、map、chan变量时，也会分配内存，类似malloc。除了make,slice还有另一种定义方式，slice := []int{}

零值

零值不是0,零值是每种类型变量在初始化后的默认值/空值

数字类型（整型、浮点数）的零值为0；bool则为false；字符串为””

结构体的零值为一个所有字段都为零值的结构体对象

其他对象则为nil

注意：Golang中，一个变量被声明后，必须要被使用，否则会在编译时报错

循环

  • 写法一： for 表达式; 表达式; 表达式 {}，类比Java的写法

  • 写法二：for 表达式 {}，等价于while

  • 写法三： for range {}，类似Python的 for range写法

    对于for range写法，主要用于array、slice、map、string、chan的遍历

循环相关关键词
break、continue - 跳出循环、跳过本次循环
goto - 类似C语言的goto

goto的限制：
1.不能跨函数跳转 2.不能跳过变量声明（及时被跳过的变量在后续不会被使用） 3. 不能跳入内层代码块（如if）
goto在目前使用较少，其两种核心用途均可被其他方式替代：

  • 集中处理错误、资源清理，目前更主流的方式是 defer()

  • 跳出多重循环，但这种情况可使用break的标签

switch 语句

  • 默认不需要 break , case 匹配后自动终止，可使用 fallthrough 显式穿透执行下一个case

  • case 可以匹配多个值

  • case 可匹配布尔条件，取代if-else

  • 支持初始化

  • case 除了匹配常量外，可匹配变量、函数返回值

  • switch 可判断接口类型，只能用于接口 interface{} / any （两者等价）

类型判断

Go中变量的判断主要有以下几种方式：

  1. val.(int)，断言，要指明要判断的类型，当单返回值时，若失败直接panic,成功返回则是对应类型。只适用于 interface{} / any

  2. val.(type)，只能用在switch中对 interface{} / any 判断

  3. 反射包 reflect，可用于普通变量的判断
