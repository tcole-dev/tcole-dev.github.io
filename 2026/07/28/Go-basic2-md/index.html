new 和 make

make() 和 new() 都是Go中内存分配函数，make只适用于slcie、map、chan，返回类型对象；而new则适用于所有类型，返回类型指针。

new会直接在堆分配一块对应类型大小的内存并置零，但不会对slice的底层数组分配内存，所以不能用于slice、map、chan

len 和 cap

len函数用于计算已用的长度，如切片中元素的个数。而cap函数用于计算总共可用的长度，如切片底层数组的长度

切片

数组和切片

数组和切片的区别只在于，数组的大小不可变，同时数组只能用**常量**初始化，使用变量即会报错

数组和切片的转换

数组 -> 切片

  • 切片表达式（切割）

    对数组进行切割时，返回的是一个与原数组共享底层数组的切片，当进行append等操作导致数组长度不足时，会进行扩容，此时才会摆脱原数组

  • 显式类型转换（低版本Go不支持）

  • copy，得到拷贝，不共享底层数组 注意：copy() 是浅拷贝

切片 -> 数组

字符串

字符串的长度

字符串本质是byte[]，len() 计算的也是字节切片的长度，所以就算中文字符串短于英语，但实际上得出的长度可能会更长

byte 和 rune

Golang中，字符串的本质是一个UTF-8编码的字节数组，所以直接通过索引访问字符串中的某个字符时，实际上输出的是字节：

在Unicode中，不同字符的编码长度不同，ASCII码中的字符（如英语字母、数字等）只占一个字节，而中文往往占三个字节，这样就引出了rune，rune表示的是一个字符

strings.Builder

Golang拼接字符串可通过 + 或转为字节切片再添加元素的方式，但性能都较差，可通过strings.Builder来进行拼接
